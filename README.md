# HotPlaykey
An ordinary audio player which only plays music by pressing a hotkey: "menu" (you can change it)

> [!WARNING]
> You need to install these following dependencies: `just_playback` and `keyboard`

You may ask *"why does it exist?"*.
Well, imagine you want some custom music in the game you're playing. But you can't modify the game assets!
And then you come up with a workaround that this script replicates. You hit a single key you don't press often, and the music you chose plays!!
Just mute the original music in game settings.
